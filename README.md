Moto’s Art Cabinet is an optional collection of AI-generated fantasy artwork for Foundry VTT. Pick the images you want through Foundry’s File Picker.

## What’s in 1.0.0

The first release includes **145 WebP icons** for items, abilities, effects, and macros. I plan to add more icons, character portraits, token art, and scene artwork in future releases.

## Compatibility

The supported baseline is **Foundry VTT 13.351**. The artwork works with any game system and requires no other modules.

## Install and use

Once the release is published, open **Add-on Modules → Install Module** in Foundry Setup and paste this manifest URL.

```text
https://github.com/MotoMoto1234/Moto-s-Art-Cabinet/releases/latest/download/module.json
```

For a manual install, extract `motos-art-cabinet-v1.0.0.zip` into your Foundry User Data `Data/modules` directory, then restart Foundry.

In your world, open an image field and browse to **User Data → modules → motos-art-cabinet → Icons**. You can also paste an image path such as `modules/motos-art-cabinet/Icons/AdamantinePlating.webp`.
